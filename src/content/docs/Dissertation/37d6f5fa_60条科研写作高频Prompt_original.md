随着生成式AI在科研写作中的应用越来越广泛，越来越多教师开始利用AI辅助完成：

  * 课题选题设计


  * 文献综述整理


  * 研究框架构建


  * 课题申报书撰写


  * 学术论文写作

但在实际使用过程中，许多教师会遇到一个问题：提示词（Prompt）不完整，生成内容不够学术、不够严谨。一个高质量科研Prompt通常应包含三个基本要素：角色设定 + 任务说明 + 输出要求例如：

请你作为一名教育科研专家，围绕“核心素养导向课堂教学改革”这一主题，为中小学教师设计5个具有研究价值的课题选题。要求每个选题包含明确的研究对象、研究内容和研究情境，选题切口适中，符合教育科研规范。为了帮助教师更加规范地使用AI工具，本文整理了 60条科研写作高频Prompt ，基本覆盖教师科研写作全过程。

课题选题设计 Prompt（10条）


请你作为一名教育科研专家，结合当前基础教育教学改革趋势，为中小学教师设计10个具有研究价值的教育科研课题选题。要求每个选题包含研究对象、研究内容和研究情境，选题切口适中，具有可操作性。

请你作为一名教育学研究者，围绕“核心素养导向课堂教学”这一研究主题，为中小学教师设计8个教育科研课题选题。要求选题结构规范，能够在真实课堂教学中开展实践研究。

请你作为一名教育科研课题评审专家，从课堂教学改进的角度，为中小学教师推荐10个具有实践研究价值的教育科研选题。要求选题明确研究对象、研究问题和研究情境。

请你作为一名教育科研专家，围绕“学生学习策略培养”这一研究方向，为中学教师设计8个具有可操作性的课题选题，并确保研究内容适合课堂教学实践研究。

请你作为一名教育科研专家，为小学语文教师推荐10个具有研究价值的课堂教学研究课题。要求研究对象明确，研究内容具体，切口适中。

请你作为一名教育科研专家，为初中数学教师设计8个适合开展课堂教学实践研究的教育科研选题。要求选题具有一定研究深度，同时具备可实施性。

请你作为一名教育科研专家，围绕“信息技术支持下课堂教学改革”这一研究主题，为中小学教师设计10个具有研究意义的教育课题选题。

请你作为一名教育科研专家，从学习评价改革的角度，为中小学教师推荐8个具有研究价值的教育科研选题。要求选题适合开展课堂实践研究。

请你作为一名教育科研专家，结合当前教育改革热点，为中小学教师设计10个具有前沿性的教育科研选题。要求研究问题明确，研究内容具体。

请你作为一名教育科研专家，请分析当前中小学课堂教学中存在的典型问题，并基于这些问题提出8个具有研究价值的教育科研课题选题。

文献综述写作 Prompt（10条）


请你作为一名教育学研究者，围绕“项目化学习在中小学课堂中的应用”这一研究主题，撰写一段教育科研文献综述。要求包括国内研究现状、主要研究方向以及研究不足。

请你作为一名教育科研专家，请围绕“核心素养背景下课堂教学改革”这一研究主题，整理相关研究成果，并撰写一段结构清晰的文献综述。

请你作为一名教育研究者，请围绕“合作学习在课堂教学中的应用研究”这一主题，梳理相关研究文献，并总结主要研究成果。

请你作为一名教育科研专家，请围绕“学习动机与学习效果关系研究”这一主题，撰写一段教育科研文献综述，并分析当前研究存在的不足。

请你作为一名教育研究者，请围绕“课堂学习评价改革”这一主题，对相关研究成果进行分类整理，并总结研究发展趋势。

请你作为一名教育科研专家，请围绕“信息技术支持课堂教学模式研究”这一主题，撰写一段文献综述，并分析研究热点。

请你作为一名教育研究者，请围绕“学生学习策略培养研究”这一主题，总结已有研究成果，并指出当前研究存在的不足。

请你作为一名教育科研专家，请围绕“课堂互动教学研究”这一主题，整理国内外研究成果，并形成一段学术性文献综述。

请你作为一名教育研究者，请围绕“课堂教学模式创新”这一主题，总结相关研究成果，并分析研究发展趋势。

请你作为一名教育科研专家，请围绕“课堂教学效率提升研究”这一主题，撰写一段文献综述，并指出未来研究方向。
